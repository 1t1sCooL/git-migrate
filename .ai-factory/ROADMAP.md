# Project Roadmap

> Единая команда бекапа: все доступные рабочие репозитории зеркалируются в личный GitLab и личный GitHub.

## Milestones

- [x] **Зеркальная миграция GitLab → GitHub** — клонирование/обновление зеркала и push --mirror, идемпотентное создание репозитория
- [x] **Зеркальная миграция GitHub → GitLab** — включая создание подгрупп по owner и перенос имён
- [x] **Безопасный запуск и автоматизация** — DRY_RUN, .env-конфигурация, Makefile с целями run/dry-run/clean
- [ ] **Обнаружение всех доступных репозиториев** — список по membership (все группы/подгруппы рабочего GitLab, а не только одна группа), фильтры include/exclude
- [x] **Профили источника и назначений** — конфигурация «рабочий git» + «личный GitLab» + «личный GitHub» с раздельными токенами и base URL
- [ ] **Режим sync (fan-out)** — один fetch из источника, push --mirror сразу в несколько назначений за один проход
- [ ] **Инкрементальное обновление** — повторные запуски обновляют существующие зеркала (fetch --prune), пропуск репозиториев без изменений
- [ ] **Единая команда бекапа** — `make backup` / `node git-migrate.js sync`: fetch всех рабочих репозиториев + бекап в оба личных git одной командой
- [ ] **Разрешение конфликтов имён** — неймспейсы рабочих групп → префиксы/группы в личных аккаунтах, защита от перезаписи чужих репозиториев
- [ ] **Отчёт о синхронизации** — итоговая сводка: обновлено / без изменений / ошибки, ненулевой exit code при сбоях
- [ ] **Запуск по расписанию** — cron/launchd-конфигурация для автоматического регулярного бекапа
